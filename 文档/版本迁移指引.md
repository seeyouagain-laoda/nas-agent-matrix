映射要点说明：

- **目录编号即推荐阅读顺序**：先看 03 的地图，再按 04 → 01 → 02 落地，升级前读 05。
- **中文目录名**：新仓库统一使用中文目录，便于直接按主题定位，不再需要靠仓库名猜内容。
- **`.git` 不迁移**：各旧仓库的版本历史保留在原仓库，新仓库从合并完成的这一刻开始记录新历史。
- **文件内容未改写**：迁移只做移动，不动正文。旧文档里出现的仓库名、相对链接可能需要按下一节更新。

## 二、旧链接如何处理

### 1. 旧仓库的处置

5 个旧仓库**不会被删除**，而是在各自 `README.md` 首行插入一条指向本仓库对应子目录的迁移横幅：

> 本仓库已迁移至 [nas-agent-matrix](https://github.com/seeyouagain-laoda/nas-agent-matrix) 的 `XX_xxx` 目录，后续更新请前往新仓库查看。

因此：

- 旧链接**不会 404**，仍可访问到历史内容；
- 但**后续更新只在新仓库进行**，旧仓库进入只读状态；
- 建议把书签、笔记中的链接更新为新的子目录地址。

### 2. 文档内部的交叉引用

旧文档之间原本用「仓库名」互相指代（例如 03 号索引里列了一串 `xxx-guide` 仓库链接）。
迁移后请注意：

| 文中提到的 | 现在应指向 |
|---|---|
| `astrbot-openclaw-whale-guide` | 本文档库 `01_AstrBot与OpenClaw双端协同/` |
| `tdai-unified-memory-guide` | 本文档库 `02_TDAI统一记忆持久化/` |
| `openclaw-fnOS-guide` | 本文档库 `04_飞牛fnOS部署指南/` |
| `openclaw-upgrade-empirical-study` | 本文档库 `05_网关破坏性升级复盘/` |
| `reverse-proxy-guide` / `mihomo-stack-guide` / `tailscale-mesh-guide` / `wechat-notify-guide` / `minimax-h3-guide` | **未纳入本仓库**，仍为独立仓库，链接保持不变 |

### 3. 外部引用的仓库

`03_NAS自建AI实操指南` 中列出的 `reverse-proxy-guide`、`mihomo-stack-guide`、
`tailscale-mesh-guide`、`wechat-notify-guide`、`minimax-h3-guide` 五个仓库
**不在本次合并范围内**，保持独立，请继续访问各自原仓库。
